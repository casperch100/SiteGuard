SiteGuard 隱私權政策

生效日期：2026 年 11 月 26 日（適用 0.2.0 版起）

SiteGuard 網站安全檢查（以下簡稱「本擴充功能」）是一個 Chrome 擴充功能，用來提醒使用者可能的詐騙、仿冒與可疑網站。我們重視你的隱私，本政策說明本擴充功能如何處理資料。

一句話說明

本擴充功能所有判斷都在你的電腦上完成，不會收集、上傳、出售或分享你的任何資料。唯一的對外連線是定期從政府資料開放平臺下載公開的詐騙網站名單，下載時不會傳送你的任何資料。

本擴充功能會讀取哪些資料

資料用途是否離開你的電腦
你正要前往的網址在網頁載入前判斷是否為危險網站，必要時顯示警告頁否
目前分頁的網址在工具列顯示安全狀態，並在彈出視窗顯示判斷結果否
網頁上連結的網址標記頁面上的危險或可疑連結，並在滑鼠移上去時顯示說明否
你反白並選擇檢查的文字只在你從右鍵選單選擇「用 SiteGuard 檢查」時，用來判斷該網址否

本擴充功能不會讀取網頁中的其他內容（例如文章、表單輸入、帳號密碼），也不會記錄你的瀏覽歷史。

本擴充功能會儲存哪些資料

以下資料只儲存在你瀏覽器的擴充功能儲存空間（chrome.storage）中：

  • 你的回報紀錄：你回報為詐騙的網域與分類。你可以隨時在彈出視窗中取消回報，或移除本擴充功能以刪除全部資料。
  • 暫時放行清單：你在警告頁選擇「仍要前往」的網域。這份清單只在本次瀏覽工作階段有效，關閉瀏覽器後自動清除。
  • 詐騙網站名單：從政府資料開放平臺下載的公開名單（見下一節），不含任何個人資料。

對外連線

本擴充功能每週一次連線到政府資料開放平臺（opdadm.moi.gov.tw），下載內政部警政署公開的「165反詐騙諮詢專線_遭停止解析涉詐網站」名單，用來更新判斷所用的詐騙網站名單。

  • 這是單純的檔案下載，不會傳送你瀏覽過的網址、回報紀錄或任何個人資料，也不會附帶 Cookie。
  • 和一般下載檔案一樣，政府伺服器會看到連線來源的 IP 位址；這部分依該平臺的隱私權政策處理。
  • 如果下載失敗，本擴充功能會繼續使用內建或上次下載的名單。

除此之外，本擴充功能不連線到任何其他伺服器。

資料分享

本擴充功能不使用任何分析或廣告服務，也不會將資料提供給任何第三方。

資料來源

詐騙網站名單來自內政部警政署 165 反詐騙諮詢專線的公開資料，依政府資料開放授權條款第 1 版使用：

  • 165反詐騙諮詢專線_遭停止解析涉詐網站
  • 165反詐騙諮詢專線_假投資(博弈)網站

本擴充功能的判斷僅供參考，不代表政府機關的立場。若對網站是否為詐騙有疑慮，請撥打 165 反詐騙諮詢專線。

符合 Chrome 線上應用程式商店使用者資料政策

本擴充功能對資料的使用遵循 Chrome 線上應用程式商店使用者資料政策（Chrome Web Store User Data Policy），包括「有限使用」（Limited Use）規定：讀取的資料僅用於提供上述網站安全檢查功能，不會轉移、出售，也不會用於廣告或判斷信用。

政策變更

若未來版本新增其他需要連線的功能，我們會先更新本政策並在擴充功能更新說明中告知，且僅傳送判斷所需的最少資訊。
