## 一、商店資訊（Store listing）

### 名稱
> 來自 `manifest.json`，上傳 zip 後自動帶入。

```
SiteGuard 網站安全檢查
```

### 摘要（manifest 的 description，上限 132 字元）

```
開網站前先幫你看一眼：辨識詐騙、仿冒與可疑網站，並標出網頁上的危險連結。
```

### 詳細說明（Description）

```
收到「包裹待領」「通行費未繳」的簡訊？朋友傳來「保證獲利」的投資群組連結？
SiteGuard 會在你打開網站之前先幫你看一眼，遇到危險網站直接擋下來，並告訴你為什麼。

【主要功能】
◆ 擋下危險網站
前往已知的詐騙網站，或明顯仿冒官方的網站時，會先顯示警告頁，讓你在輸入任何資料前停下來。

◆ 工具列即時顯示安全狀態
✓ 可信任網站　? 可疑，請小心　! 危險網站

◆ 網頁上的危險連結一眼看出來
在網頁、網頁版信箱或聊天室裡，危險連結會加上紅框、可疑連結加上橘色虛線框。滑鼠移到連結上，就會顯示判斷原因。

◆ 右鍵就能檢查
對連結或一段網址按右鍵，選「用 SiteGuard 檢查」。

◆ 一鍵回報
覺得網站有問題？點工具列圖示就能回報，之後再遇到同一個網站會直接提醒你。

【如何判斷】
除了詐騙網站名單之外，SiteGuard 也會辨識常見的仿冒手法：
・用形近字仿冒官方網址（例如把 l 換成 1）
・和官方網站同名，但網域後綴不同
・網址含有銀行、購物網站等品牌名稱，但不是官方網站
・用「@」偽裝網址、直接使用 IP 位址
・剛註冊不久的網域、詐騙網站常用的網域後綴
每個判斷都會附上看得懂的原因，不只是一個紅燈。

【重視隱私】
所有判斷都在你的電腦上完成。SiteGuard 不會上傳你的瀏覽網址、不使用任何分析或廣告服務，也不會收集個人資料。

【提醒】
SiteGuard 能降低受騙風險，但無法保證辨識所有詐騙網站。遇到可疑情況，請撥打 165 反詐騙諮詢專線。
```

## 二、隱私權（Privacy practices）

### 單一用途說明（Single purpose）

```
在使用者瀏覽網頁時，辨識並警告詐騙、仿冒與可疑網站，包括使用者正要前往的網站，以及網頁上出現的連結。
```

### 權限理由（Permission justification）

**webNavigation**
```
在網頁開始載入前取得使用者正要前往的網址，判斷是否為詐騙網站；若是，則在網頁載入前顯示警告頁，避免使用者在詐騙網站上輸入資料。
```

**storage**
```
在使用者的電腦上儲存使用者回報的可疑網站，以及使用者在警告頁選擇「仍要前往」的網域（僅限本次瀏覽工作階段）。資料不會上傳。
```

**contextMenus**
```
提供右鍵選單「用 SiteGuard 檢查這個連結」，讓使用者在點擊前先檢查連結或反白的網址是否安全。
```

**主機權限（Host permissions：<all_urls>）與內容腳本**
```
詐騙網站可能出現在任何網域，因此需要在所有網站上運作：(1) 取得目前分頁的網址以在工具列顯示安全狀態；(2) 讀取網頁上連結的網址，標記危險連結並在滑鼠移上去時顯示說明。只讀取連結網址，不讀取網頁其他內容；所有判斷都在本機完成，不會傳送任何資料。
```

### 遠端程式碼（Remote code）
選 **「否，我沒有使用遠端程式碼」**。

### 資料使用（Data usage）
- 「本擴充功能會收集哪些使用者資料」：**全部不勾選**（所有資料都只在本機處理，不會傳出）。
- 下方三項聲明**全部勾選**：
  - 不會將使用者資料出售或轉移給第三方（核准用途除外）
  - 不會將使用者資料用於與單一用途無關的目的
  - 不會將使用者資料用於判斷信用或放款
