SiteGuard 隱私權政策

生效日期：2026 年 11 月 27 日（適用 0.3.0 版起）；同日更新：新增「判斷錯了？」回報連結的說明

SiteGuard 網站安全檢查（以下簡稱「本擴充功能」）是由 casperch100（以下簡稱「我們」）開發與發布的 Chrome 擴充功能，用來提醒使用者可能的詐騙、仿冒與可疑網站。我們重視你的隱私，本政策說明本擴充功能如何處理資料。

一句話說明

本擴充功能所有判斷都在你的電腦上完成，不會收集、出售或分享你的資料，也沒有我們自己的伺服器。自動的對外連線只有兩種：每週從政府資料開放平臺下載公開的詐騙網站名單；以及開啟沒查過的網站時，向該網域的註冊管理機構查詢註冊日期（只送出網域名稱，可在設定中關閉）。另外，只有在你主動點選「判斷錯了？」時，才會在 GitHub 開啟預先填好網域的回報表單。詳見下方「對外連線」。

本擴充功能會讀取哪些資料

資料用途是否離開你的電腦
你正要前往的網址在網頁載入前判斷是否為危險網站，必要時顯示警告頁網址本身不會。若需要查詢註冊日期，只會把網域名稱（例如 example.com）送到該網域的註冊管理機構（見「對外連線」）
目前分頁的網址在工具列顯示安全狀態，並在彈出視窗顯示判斷結果否
網頁上連結的網址標記頁面上的危險或可疑連結，並在滑鼠移上去時顯示說明否（不會為了網頁上的連結查詢註冊日期）
你反白並選擇檢查的文字只在你從右鍵選單選擇「用 SiteGuard 檢查」時，用來判斷該網址否

本擴充功能不會讀取網頁中的其他內容（例如文章、表單輸入、帳號密碼），也不會保存你的瀏覽歷史（網域註冊日期的快取只保存網域與日期，不含造訪時間或網址）。

本擴充功能會儲存哪些資料

以下資料只儲存在你瀏覽器的擴充功能儲存空間（chrome.storage）中：

  • 你的回報紀錄：你回報為詐騙的網域與分類。你可以隨時在彈出視窗中取消回報，或移除本擴充功能以刪除全部資料。
  • 暫時放行清單：你在警告頁選擇「仍要前往」的網域。這份清單只在本次瀏覽工作階段有效，關閉瀏覽器後自動清除。
  • 詐騙網站名單：從政府資料開放平臺下載的公開名單（見下一節），不含任何個人資料。
  • 網域註冊日期快取：查詢過的網域與它的註冊日期，保存 30 天（查不到的保存 1 天），最多 3,000 筆。可以在設定頁隨時清除。
  • 設定：例如是否查詢網域註冊日期。

對外連線

1. 下載詐騙網站名單

本擴充功能每週一次連線到政府資料開放平臺（opdadm.moi.gov.tw），下載內政部警政署公開的「165反詐騙諮詢專線_遭停止解析涉詐網站」名單，用來更新判斷所用的詐騙網站名單。

  • 這是單純的檔案下載，不會傳送你瀏覽過的網址、回報紀錄或任何個人資料，也不會附帶 Cookie。
  • 和一般下載檔案一樣，政府伺服器會看到連線來源的 IP 位址；這部分依該平臺的隱私權政策處理。
  • 如果下載失敗，本擴充功能會繼續使用內建或上次下載的名單。

2. 查詢網域註冊日期（可關閉）

剛註冊不久的網域比較可能是詐騙網站，所以當你開啟一個沒查過的網站，或在彈出視窗中主動查詢某個網址時，本擴充功能會用公開的 RDAP 協定，向該網域的註冊管理機構查詢註冊日期。例如 .com 網域查詢 Verisign，.tw 網域查詢台灣網路資訊中心（TWNIC）。各頂級網域該向哪個機構查詢，依據 IANA 公布的對照表，內建在擴充功能中。

  • 只送出網域名稱（例如 example.com），不送出完整網址、路徑、查詢參數，也不附帶 Cookie 或來源網頁資訊。
  • 直接查詢註冊管理機構，不經過任何第三方，也不經過我們（我們沒有伺服器）。
  • 不查詢的情況：可信任網站（例如大型入口網站、銀行與購物網站的官方網域）、政府與學術網站、已列入 165 名單的網站、共用平台的子網域（例如 xxx.github.io，查到的會是平台本身的日期）、IP 位址與本機網址，以及網頁上的連結（標記與滑過提示只使用已查過的結果）。
  • 查詢結果在你的電腦上保存 30 天，期間內不會重複查詢同一個網域。
  • 註冊管理機構會看到「有人查詢了某個網域」以及連線來源的 IP 位址；這部分依各機構的隱私權政策處理。
  • 你可以隨時關閉：在擴充功能的「設定」頁取消勾選「查詢網域註冊日期」。關閉後就不會再查詢，但新出現的詐騙網站會比較難辨識。

3. 你主動點選「判斷錯了？」時（開啟 GitHub 回報頁面）

彈出視窗與警告頁有「判斷錯了？回報誤判」或「回報給開發者」連結。只有你點選時，瀏覽器才會在新分頁開啟本專案在 GitHub 的回報表單。

  • 表單網址中預先帶入網域名稱（例如 example.com）、SiteGuard 的判斷結果與原因，以及擴充功能版本；不會帶入完整網址、路徑或查詢參數。
  • 開啟頁面時，GitHub 會看到這個網址（包含上述網域）；這部分依 GitHub 的隱私權政策處理。
  • 你可以修改或刪除表單內容。按下送出後，回報會公開顯示在 GitHub 上；不送出就不會建立回報。送出需要 GitHub 帳號。

除了以上三種，本擴充功能不連線到任何其他伺服器。

資料分享

本擴充功能不使用任何分析或廣告服務，不會出售資料，也不會將資料提供給第三方，唯一的例外是上述「查詢網域註冊日期」時送給註冊管理機構的網域名稱，用途僅限於判斷該網站是否可疑。

資料來源

詐騙網站名單來自內政部警政署 165 反詐騙諮詢專線的公開資料，依政府資料開放授權條款第 1 版使用：

  • 165反詐騙諮詢專線_遭停止解析涉詐網站
  • 165反詐騙諮詢專線_假投資(博弈)網站

本擴充功能的判斷僅供參考，不代表政府機關的立場。若對網站是否為詐騙有疑慮，請撥打 165 反詐騙諮詢專線。

符合 Chrome 線上應用程式商店使用者資料政策

本擴充功能對資料的使用遵循 Chrome 線上應用程式商店使用者資料政策（Chrome Web Store User Data Policy），包括「有限使用」（Limited Use）規定：讀取的資料僅用於提供上述網站安全檢查功能，不會轉移、出售，也不會用於廣告或判斷信用。

政策變更

若未來版本新增其他需要連線的功能，我們會先更新本政策並在擴充功能更新說明中告知，且僅傳送判斷所需的最少資訊。
